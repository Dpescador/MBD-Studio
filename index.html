PProjetosVários diagramas no mesmo MDB Studio
  1. Clique no botão Projeto da barra superior.
  2. Informe um nome e clique em Criar projeto para iniciar um diagrama vazio.
  3. Clique em um projeto da lista para alternar entre os modelos.
  4. Use os botões laterais para renomear, duplicar ou excluir.

Antes da troca, o projeto atual é salvo automaticamente. Cada projeto mantém suas próprias tabelas, posições e relacionamentos.

Atalho: pressione Ctrl + Shift + N para abrir o gerenciador de projetos.
Backup: o vínculo do arquivo TXT é individual para cada projeto. Ao mudar de projeto, confira o indicador de backup na parte inferior da tela.
▦Tabelas e camposCriação, edição e propriedades
  1. Clique em Nova tabela.
  2. Informe o nome e escolha a cor do cabeçalho.
  3. Use Adicionar campo para criar as colunas.
  4. Preencha o nome e o tipo, por exemplo NUMBER, VARCHAR2(150) ou TIMESTAMP.
  5. Marque PK, NOT NULL ou UNIQUE quando necessário.
  6. Em Default, informe somente a expressão, como 'ATIVO', 0 ou CURRENT_TIMESTAMP.
  7. Em ENUM, informe valores separados por vírgula, como ATIVO, INATIVO, BLOQUEADO.
Dica: campos com valor padrão ou enumeração exibem as legendas DEFAULT e ENUM no diagrama. Passe o mouse para consultar os valores.

Árvore lateral

  • Um clique no nome da tabela centraliza e seleciona a tabela.
  • Dois cliques abrem o editor individual de script SQL.

Menu da tabela

Clique em ⋮ no cabeçalho para editar a tabela, editar o SQL, alterar relacionamentos, mudar a cor, duplicar ou excluir.

↗Relacionamentos1:1, 1:N e N:N
  1. Clique em Relacionamento ou pressione R.
  2. Clique primeiro no campo de origem, normalmente a chave estrangeira.
  3. Clique depois no campo de destino, normalmente a chave primária referenciada.
  4. Escolha a cardinalidade e informe uma descrição opcional.
  5. Confirme para criar a ligação.

Dê dois cliques na linha para editar a cardinalidade e a descrição.

Ao selecionar um campo relacionado, o sistema destaca os campos ligados, a linha, a seta de referência e as cardinalidades. Clique em uma área vazia para remover o destaque.

Atenção: relacionamentos N:N são mantidos visualmente. Para gerar o modelo físico, crie uma tabela associativa.
</>SQL nativoCriação e atualização por DDL

Clique em SQL nativo, escolha Adicionar ou Substituir e cole o DDL.

  • Adicionar: mantém o diagrama atual e inclui as novas tabelas.
  • Substituir: remove o conteúdo atual e carrega somente o script informado.

O parser reconhece CREATE TABLE, PRIMARY KEY, UNIQUE, NOT NULL, DEFAULT, ENUM, CHECK ... IN (...), REFERENCES e chaves estrangeiras adicionadas por ALTER TABLE.

Editar apenas uma tabela

Dê dois cliques na tabela da árvore lateral ou abra ⋮ → Editar script SQL. O editor aceita um CREATE TABLE e comandos ALTER TABLE referentes à própria tabela.

⇄Importar e exportarJSON, TXT, SQL, SVG e HTML

Importar

Use Importar para carregar um projeto JSON, um backup TXT ou um script SQL. Antes de substituir o projeto, exporte uma cópia de segurança.

Exportar

  • Projeto JSON: mantém o modelo editável para continuar o trabalho depois.
  • Script SQL: gera DDL para Oracle, PostgreSQL ou MySQL.
  • Imagem SVG: produz uma imagem vetorial do diagrama.
  • Página HTML independente: gera um único HTML com o diagrama, zoom, movimentação, tema e tooltips.
  • Backup TXT: baixa uma cópia completa do projeto em texto.
TXTBackup externo em TXTProteção contra limpeza do cache
  1. Clique em Backup TXT.
  2. Use Vincular arquivo TXT e escolha onde salvar o arquivo.
  3. Autorize a gravação quando o navegador solicitar.
  4. Após o vínculo, as alterações concluídas são gravadas automaticamente.

Para recuperar o projeto depois de limpar o cache, abra Backup TXT → Restaurar outro backup TXT e selecione o arquivo salvo.

Importante: o navegador pode esquecer a autorização do arquivo depois de limpar os dados. O TXT continua no computador; basta selecioná-lo novamente para restaurar.

O salvamento direto funciona melhor no Chrome ou Edge quando o sistema é aberto por um servidor local:

python -m http.server 8080

Depois acesse http://localhost:8080.

O arquivo TXT não é salvo automaticamente.
Abra por http://localhost:8080, use Chrome ou Edge e vincule novamente o arquivo.
O SQL não foi importado como esperado.
Revise comandos específicos do banco, comentários incomuns e restrições compostas. Teste blocos menores para localizar o trecho incompatível.
Não consigo localizar uma tabela.
Use a busca lateral ou clique em Ajustar para enquadrar o diagrama completo.
